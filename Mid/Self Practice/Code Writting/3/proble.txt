3.	Create an HTML form with a single text field to accept a User’s Age for a community membership check.
Using JavaScript, display a dynamic message below the input field as follows:
•	If the age is less than 40:
→ Show "To be a part of the community, you need to at least 40".
•	If the age is between 40 and 50 (inclusive):
→ Show "You are the youngsters of this community".
•	If the age is greater than 50:
→ Show "Top level members of the group" in red text.
