Introduction to PHP

PHP stands for PHP: Hypertext Preprocessor — a recursive acronym. It is a server-side scripting language used to build dynamic and interactive web pages.

  • PHP scripts execute on the server; result is returned as plain HTML to the browser.
  • PHP files have the .php extension and can contain HTML, CSS, JavaScript, and PHP code.
  • PHP is free, open-source, and runs on various platforms (Windows, Linux, Mac).
  • Compatible with almost all servers (Apache, IIS, etc.) and databases (MySQL, Oracle, etc.).
  • Latest stable release: PHP 8 (notes reference PHP 7+).

What can PHP do?

  • Generate dynamic page content
  • Create, open, read, write, delete, close files on the server
  • Collect form data
  • Send and receive cookies
  • Add, delete, modify data in a database
  • Control user-access and encrypt data

Installation — XAMPP: XAMPP (Apache + MariaDB/MySQL + PHP + Perl) is the most popular PHP development environment. After installation, save PHP files in C:\xampp\htdocs\<AppName>\ and browse http://localhost/<AppName>/file.php.

PHP Script syntax:

<?php
echo "Hello World!";
?>
  • Starts with <?php and ends with ?>.
  • Keywords, classes, functions are NOT case-sensitive (e.g., echo, ECHO, EcHo are all valid).
  • Variable names ARE case-sensitive ($age ≠ $AGE).
  • echo vs print: echo has no return value, can take multiple params; print returns 1, takes one argument.

PHP Syntax, Variables & Data Types

Variables

  • Variables start with $ sign: $name = "John";
  • Must start with a letter or underscore (not a number).
  • Can only contain alphanumeric characters and underscores (A-z, 0-9, _).
  • PHP is loosely typed — no need to declare data type before a variable.
  • PHP automatically assigns data types to variables.

Arrays & Built-in Array Functions

Indexed Array: $cars = array("Volvo","BMW","Toyota"); — access with $cars[0].

Associative Array: named keys:

$car = array("brand"=>"Ford", "model"=>"Mustang", "year"=>1964);
echo $car["model"]; // Mustang

Iterate with foreach:

foreach($car as $x => $y) { echo "$x: $y <br>"; }

Key Built-in Array Functions:

  • count($arr) — number of elements
  • is_array($var) — returns TRUE if array
  • in_array($val, $arr) — TRUE if value in array
  • sort($arr) / rsort($arr) — sort ascending / descending (modifies array in-place)
  • shuffle($arr) — random order (in-place)
  • implode($glue, $arr) — join array to string: implode('|', $a) → "apple|orange"
  • explode($delimiter, $str) — split string into array
  • array_push($arr, $val) — add to END; also $arr[] = $val
  • array_pop($arr) — remove & return LAST element
  • array_shift($arr) — remove & return FIRST element
  • array_unshift($arr, $val) — add to BEGINNING
  • reset($arr) / end($arr) — first / last element

Cookies

  • A cookie is a small file the server embeds on the user's computer to identify them.
  • Every request to the same site sends the cookie back to the server.
  • setcookie() must be called BEFORE any HTML output (<html> tag).
setcookie(name, value, expire, path, domain, secure, httponly);

// Example: cookie valid for 30 days
setcookie("user", "Alex", time() + (86400 * 30), "/");
// 86400 seconds = 1 day

// Read cookie
echo $_COOKIE["user"];

// Delete cookie: set expiration in the past
setcookie("user", "", time() - 3600);

// Check if cookies enabled
if(count($_COOKIE) > 0) echo "Enabled";
else echo "Disabled";

Cookie types:

  • Session cookies — disappear when browser is closed (no expiry set)
  • Persistent cookies — stored until expiry date
  • Tracking cookies — used for long-term records across visits

If a cookie is set without an expiration time, it is a session cookie — it lasts only until the browser is closed.

Sessions

  • A session stores information in server-side variables accessible across multiple pages.
  • Unlike cookies, session data is NOT stored on the user's computer.
  • Each user gets a unique session ID.
  • session_start() must be the very first line in the document (before any HTML).
// Start session
<?php session_start(); ?>

// Set session variable
$_SESSION["favcolor"] = "yellow";

// Read session variable
echo $_SESSION["favcolor"];

// Display all session variables
print_r($_SESSION);

// Remove all session variables (keeps session)
session_unset();

// Destroy the session completely
session_destroy();

PHP Include Files & File Upload

include vs require:

  • include — produces a warning (E_WARNING) on failure; script continues.
  • require — produces a fatal error (E_COMPILE_ERROR) on failure; script stops.
<?php include 'footer.php'; ?>
<?php require 'config.php'; ?>

File Upload:

  • Enable in php.ini: file_uploads = On
  • Form must use method="post" AND enctype="multipart/form-data"
  • Uploaded file info is in $_FILES superglobal.
  • PHP places file in a temporary location first.
  • Use move_uploaded_file() to move from temp to final location.
<form action="upload.php" method="post" enctype="multipart/form-data">
  <input type="file" name="fileToUpload">
  <input type="submit" value="Upload">
</form>
// upload.php
$target_dir = "uploads/";
$target_file = $target_dir . basename($_FILES["fileToUpload"]["name"]);

if(move_uploaded_file($_FILES["fileToUpload"]["tmp_name"], $target_file)){
    echo "Uploaded: " . basename($_FILES["fileToUpload"]["name"]);
}

$_FILES array keys: ['name'], ['type'], ['size'], ['tmp_name'], ['error']

AJAX

AJAX = Asynchronous JavaScript And XML. It is NOT a programming language — it is a technique for accessing web servers from a web page without full-page reload.

  • Uses XMLHttpRequest object (built into browsers)
  • Can update parts of a page without reloading
  • Sends/receives data in the background

How AJAX works (7 steps):

  1. An event occurs in the web page
  2. XMLHttpRequest object is created by JavaScript
  3. XMLHttpRequest sends request to web server
  4. Server processes the request
  5. Server sends response back to the page
  6. Response is read by JavaScript
  7. JavaScript updates the page

XMLHttpRequest Methods:

MethodDescription
new XMLHttpRequest()Creates the object
open(method,url,async)Specifies request type, URL, async mode
send()Sends GET request
send(string)Sends POST request
setRequestHeader()Adds HTTP header
abort()Cancels current request
getAllResponseHeaders()Returns all header info

readyState values: 0=not initialized, 1=connected, 2=received, 3=processing, 4=ready

HTTP status: 200=OK, 403=Forbidden, 404=Not Found

var xhttp = new XMLHttpRequest();
xhttp.onreadystatechange = function() {
    if (this.readyState == 4 && this.status == 200) {
        document.getElementById("demo").innerHTML = this.responseText;
    }
};
xhttp.open("GET", "ajax_info.txt", true); // true = async
xhttp.send();

jQuery

jQuery is a lightweight JavaScript library ("write less, do more"). It simplifies HTML/DOM manipulation, CSS manipulation, AJAX, event handling, and animations.

Basic syntax: $(selector).action()

  • $ — defines jQuery
  • selector — finds HTML elements
  • action() — performed on elements
$(this).hide()        // hides current element
$("p").hide()         // hides all <p>
$(".test").hide()     // hides all class="test"
$("#test").hide()     // hides id="test"

Selectors:

SelectorSyntaxFinds
Element$("p")All <p> elements
ID$("#test")Element with id="test"
Class$(".test")Elements with class="test"

Common Event Methods: click(), dblclick(), mouseenter(), mouseleave(), mousedown(), mouseup(), hover(), focus(), blur(), on()

$(document).ready(function(){       // Run when DOM is loaded
    $("p").click(function(){
        $(this).hide();
    });
    $("p").on({                       // Multiple events
        mouseenter: function(){ $(this).css("background","lightgray"); },
        click:      function(){ $(this).css("background","yellow"); }
    });
});

MVC Architecture

MVC = Model — View — Controller. An application design pattern that separates application data and business logic from presentation.

ComponentRoleExamples
ModelManages data & business rules; database operations (fetch/update)Database class, data access layer
ViewPresentation / GUI; what user seesHTML, CSS templates
ControllerMediator between Model & View; handles user requests; business logicPHP controller classes

How it works: User request → Controller → Model (data) → Controller → View (rendered HTML) → User.

MVC Advantages: Faster development, multiple devs can collaborate, easier to update/debug, separation of concerns.

MVC Disadvantages: Hard to understand initially, strict rules needed.

Popular PHP MVC Frameworks: Laravel, CodeIgniter, Symfony, CakePHP, Yii, Zend Framework.

1. The $_REQUEST superglobal typically contains the contents of ________
A. $_GET and $_POST only
B. $_GET, $_POST, and $_COOKIE
C. $_SESSION
D. $_FILES and $_ENV
✔ Answer: B — $_REQUEST is a superglobal that by default contains the combined contents of $_GET, $_POST, and $_COOKIE. It allows you to collect data from both GET and POST form submissions as well as cookies using a single variable.
2. Which function removes all session variables but does not destroy the session itself?
A. session_destroy()
B. session_unset()
C. unset($_SESSION)
D. clearstatcache()
✔ Answer: B — session_unset() frees all session variables currently registered (clears $_SESSION array) but keeps the session active. session_destroy() completely destroys the session. You typically call both when logging a user out.
Scenario — Questions 3 to 6
The "Sweet Loaf" bakery's new website has a page for submitting cupcake recipes. The form is set up to send the data to upload.php, and the text fields for the recipe name and description work perfectly. However, when customers try to submit a photo of their creation, the server receives no file data, leaving the image upload feature broken.
3. What is the most likely cause of this problem?
A. The file input element is missing the required attribute
B. The form is missing the enctype="multipart/form-data" attribute
C. The server's PHP configuration has file_uploads set to Off
D. The form's method="post" attribute is incorrect
✔ Answer: B — Without enctype="multipart/form-data" in the form tag, file data is NOT transmitted to the server — only text field data is sent. This is the most common and classic cause of broken file uploads. Text fields work because the default encoding (application/x-www-form-urlencoded) handles them fine.
4. Once the form is fixed, the uploaded image will first be placed in:
A. A folder named /tmp/ on the server's root
B. The same directory as the upload.php script
C. PHP server temp storage
D. A special database table for file storage
✔ Answer: C — PHP automatically places uploaded files in a temporary server storage location first (configured via upload_tmp_dir in php.ini). The path to this temp file is available via $_FILES['field']['tmp_name']. You must use move_uploaded_file() to move it to a permanent location.
5. The server-side script will find details about the uploaded image, like its original name and size, in which PHP superglobal?
A. $_POST
B. $_GET
C. $_FILES
D. $_REQUEST
✔ Answer: C — $_FILES is the dedicated superglobal for file uploads. It contains keys: ['name'] (original filename), ['type'] (MIME type), ['size'] (bytes), ['tmp_name'] (temp path), and ['error'] (error code).
6. To securely save the file to a public gallery folder, the script must:
A. Use copy() on $_FILES['image']['name']
B. Check ['type'] then use fwrite()
C. Use move_uploaded_file() on $_FILES['image']['tmp_name']
D. Read $_POST['image'] and save as file
✔ Answer: C — move_uploaded_file($_FILES['image']['tmp_name'], $destination) is the correct and SECURE way. It validates that the file was genuinely uploaded via HTTP POST (preventing attacks) and then moves it from temp storage to the final destination. Using copy() or fwrite() bypasses these security checks.
7. What will be the output of the following code? $str = "hello"; echo $str[-1];
A. h
B. o
C. Error
D. Null
✔ Answer: B — PHP (since version 7.1) supports negative string indexing. $str[-1] accesses the LAST character of the string. The string "hello" has characters: h(0), e(1), l(2), l(3), o(4), so $str[-1] → "o".
8. In a sorting algorithm tester, $nums = array(3,1,4); sort($nums); echo implode(',', $nums); What will be the output?
A. 1,3,4
B. 3,1,4
C. 4,3,1
D. Error
✔ Answer: A — sort() sorts the array in ascending order (lowest to highest) and modifies it in-place. So array(3,1,4) becomes array(1,3,4). Then implode(',', $nums) joins with commas → "1,3,4".
9. For an e-commerce cart, you want to add a new item to the END of $cart = ['shirt', 'hat'];. Which function achieves this?
A. array_insert()
B. array_push()
C. array_add()
D. array_addAtEnd()
✔ Answer: B — array_push($cart, 'shoes') pushes one or more elements onto the END of an array. Equivalently you can write $cart[] = 'shoes';. Options A, C, and D are not real PHP functions.
10. You need to check if a string $email contains the "@" character. Which function is most suitable?
A. strcmp()
B. strpos()
C. strstr()
D. substr()
✔ Answer: B — strpos($email, "@") returns the position of "@" if found, or false if not. It is the most efficient and idiomatic way to check for a substring. Note: use strict comparison (!== false) since position 0 would be falsy. strcmp() compares two strings; substr() extracts a portion.
11. A PHP script receives this URL http://localhost/wt/welcome.php?key=xyz. Which of the following syntax can be used to retrieve the query value?
A. $_GET['key']
B. $_POST['key']
C. $_REQUEST['key']
D. Both A & C
✔ Answer: D — URL query parameters (like ?key=xyz) are accessible via $_GET['key'] AND via $_REQUEST['key'] (since $_REQUEST merges $_GET, $_POST, and $_COOKIE). $_POST['key'] only works for data sent in the HTTP body via POST method.
12. In PHP, if a cookie is set without specifying an expiration time, what will happen?
A. The cookie will be stored permanently until manually deleted
B. The cookie will last only for the current browser session
C. The cookie will expire immediately
D. The cookie will default to a 24-hour expiration time
✔ Answer: B — When setcookie("name","value") is called without an expiry, PHP sets no expiry date on the cookie. The browser treats this as a session cookie — it disappears when the browser is closed. To make a cookie persist, you must set an explicit expiry: e.g., time() + (86400 * 30).
